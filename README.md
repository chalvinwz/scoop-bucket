# chalvinwz/scoop-bucket

[Scoop](https://scoop.sh) manifests for tools by [chalvinwz](https://github.com/chalvinwz).

## Usage

```powershell
scoop bucket add chalvinwz https://github.com/chalvinwz/scoop-bucket
scoop install chalvinwz/<app>
```

Update with `scoop update <app>`.

## Apps

| App | Description |
| --- | ----------- |
| [lazyssm](https://github.com/chalvinwz/lazyssm) | Terminal UI for AWS SSM Session Manager |

Each project has one manifest in `bucket/`. Manifests are updated by each
project's release workflow; changes made here by hand are overwritten on the
next release.
